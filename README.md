# supply-chain-analysis
## Project overview
This project focuses on Supply Chain Analysis. The objective is to analyze the dataset to uncover insights regarding sales performance, logistics and delivery risks.

## Data Source
The dataset used in this project is available on Kaggle:
[DataCo Smart Supply Chain for Big Data Analysis](https://www.kaggle.com/datasets/shashwatwork/dataco-smart-supply-chain-for-big-data-analysis)

You can download the dataset directly from the link above.
